r = np.sqrt(x[i]**2 + y[i]**2)   # 중심까지 거리 계산
ax = -GM * x[i] / r**3           # 중력 가속도 x
ay = -GM * y[i] / r**3           # 중력 가속도 y
vx[i+1] = vx[i] + ax*dt          # 속도 업데이트 (가속도가 속도를 바꿈)
vy[i+1] = vy[i] + ay*dt
x[i+1] = x[i] + vx[i+1]*dt       # 위치 업데이트
y[i+1] = y[i] + vy[i+1]*dt

vx[1+1] & x[i+1] 이 방식이 euler integration !

[결론]
- Leapfrog 방법은 안정적이지만, dt가 커지면 정확도가 감소함 
- dt가 증가함에 따라 에너지 오차는 증가했지만, 짧은 시간 스케일에서는 궤도 형태의 변화는 크게 관찰되지 않았다.
