프로젝트 시작 

mkdir python_practice      # 새 프로젝트 폴더
cd python_practice
python -m venv venv        # 가상환경 생성
venv\Scripts\activate      # 가상환경 켜기 (Windows)
deactivate                 # 가상환경 끄기


VS CODE 연결 
VS Code에서 폴더 열기 (Open Folder) → python_practice

왼쪽 탐색기에서 새 파일 만들기 아이콘 📄 → main.py

Ctrl + Shift + P → Python: Select Interpreter → ./venv 선택

코드 작성 & 실행
# main.py
print("Hello, world!")
python main.py

패키지 관리 
pip install <패키지명>       # 예: pip install black pytest
pip list                     # 설치 패키지 확인
pip freeze > requirements.txt   # 환경 기록
pip install -r requirements.txt # 환경 복원
